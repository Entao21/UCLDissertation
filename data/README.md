# Data

Only small reference files are stored in this repository. Large rasters and
Earth Engine exports are excluded by `.gitignore`.

## Included Reference Files

| File | Purpose |
|---|---|
| `reference/asgm_global_sites.csv` | Reference river-mining locations derived from the public data accompanying Dethier et al. (2023), used for navigation and site assignment in GEE. |
| `reference/amw_scar2024_test_boxes.geojson` | Derived subset of Amazon Mining Watch polygons clipped to the four held-out South American AOIs for external agreement analysis. |

These files are included to document the completed analysis. The AlphaEarth and
Amazon Mining Watch datasets require CC BY 4.0 attribution. Consult all original
sources and their terms before redistribution or reuse.

## Source Data

| Dataset | Resolution / unit | Use | Source |
|---|---:|---|---|
| AlphaEarth Satellite Embedding V1 Annual | 10 m, 64 bands | Classification features and river-change features | [Earth Engine catalogue](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL) |
| Sentinel-2 SR Harmonized | 10-20 m | Visual interpretation basemap | [Earth Engine catalogue](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED) |
| JRC Global Surface Water v1.4 | 30 m | Permanent-water masking | [Earth Engine catalogue](https://developers.google.com/earth-engine/datasets/catalog/JRC_GSW1_4_GlobalSurfaceWater) |
| HydroBASINS / HydroRIVERS | level-12 basins / river vectors | Catchment topology and river stations | [HydroSHEDS](https://www.hydrosheds.org/) |
| Amazon Mining Watch | annual mining-scar raster | Independent agreement check and upstream mining area | [Source Cooperative](https://source.coop/earthgenome/amazon-mining-watch) |

The global river-mining site source is Dethier et al. (2023), *A global rise in
alluvial mining increases sediment load in tropical rivers*. The accompanying
data are archived on [Zenodo](https://zenodo.org/records/7699122), with code at
[evandethier/global-alluvial-mining](https://github.com/evandethier/global-alluvial-mining).

Required AlphaEarth attribution: "The AlphaEarth Foundations Satellite
Embedding dataset is produced by Google and Google DeepMind."

The downstream notebook expects a local copy named `amw_scar2024.tif` or any
file matching `amw_scar2024*.tif`. It is not committed to Git.

## Downstream Exports

The downstream notebook searches for:

```text
sa9_v8_basins_TAPAJOS_CUSTOM.geojson
sa9_v8_basin_alphaSt_2019_TAPAJOS_CUSTOM_b150_chunk*.csv
sa9_v8_basin_alphaSt_2024_TAPAJOS_CUSTOM_b150_chunk*.csv
amw_scar2024.tif
```

Optional NDTI sensitivity files use this pattern:

```text
sa9_v8_basin_ndti_byBasin_2019_TAPAJOS_CUSTOM*.csv
sa9_v8_basin_ndti_byBasin_2024_TAPAJOS_CUSTOM*.csv
```

Generated analysis tables and figures are written by the notebooks to their
configured output directories and are not versioned here.
